Welcome to my interactive **Space Theme Portfolio** — an immersive cosmic journey through my work as a backend engineer.

## ✨ Highlights

- **Immersive Space UI**
  Animated starfield, black hole hero video, and cosmic gradients.

- **Backend-Focused Content**
  Java, Spring Boot, microservices, secure APIs, and system design.

- **Project Showcase**
  Featured repositories — Campus Exam Scheduler, RentLoop, GateKeeper, and the Sleep Apnea Prediction System.

- **Fully Responsive**
  Tuned for a fluid experience on desktop and mobile.

## 🛠️ Tech Stack

- **Framework:** Next.js 16 (App Router), React 19, TypeScript
- **Styling:** Tailwind CSS
- **3D & Animation:** Three.js, React Three Fiber, Framer Motion
- **Icons:** Heroicons, React Icons

## 🚀 Quick Start

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) to view the portfolio.
